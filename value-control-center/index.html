How every number is made

Definitions are frozen before a pilot starts. Anything assumed is labelled as an assumption.

Portfolio metric definitions

How the portfolio view calculates each figure.

When there is no reliable baseline

  1. Build a comparison cohort with matched case types, severity and path.
  2. Time-box a quiet baseline week and freeze definitions first.
  3. Use scenario suites when production history is too noisy.
  4. Show ranges and assumptions instead of false precision.
  5. Report deltas with method notes, never absolutes without a denominator.

Attribution limits

  1. Pilots combine tuning, process, playbooks and AI. Never credit AI alone.
  2. Fewer incidents is not less risk without coverage context.
  3. Keep observations, calculations, assumptions and verified figures apart.
  4. Watch for confounders: seasonality, staffing, attacker behaviour, logging gaps.
  5. Say “associated with” until a causal design exists.
